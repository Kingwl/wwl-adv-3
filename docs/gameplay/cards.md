# 卡牌设计

## 设计目标

第一版卡池服务三个目标：

- 让玩家理解严格的费用阶梯会延续连击：上一张牌 2 费时，下一张只有 3 费能续连，同费、低费或跳到 4 费都会重置。
- 让攻击、防御和抽牌都能进入同一套出牌顺序决策。
- 只保留攻击类、防御类和抽卡类三种纯效果卡，避免奖励系统还没接入时引入过多特殊结算。

## 起始牌组

| 卡牌 | 费用 | 效果 | 数量 | 作用 |
| --- | ---: | --- | ---: | --- |
| 打击 | 1 | 造成 6 伤害 | 3 | 基础攻击 |
| 闪电 | 2 | 造成 9 伤害 | 2 | 0/1 费后续连的自然收尾 |
| 防守 | 1 | 获得 5 护甲 | 2 | 基础防御 |
| 专注 | 0 | 抽 1 张牌 | 1 | 找牌，但可能打断连击 |

## 第一批奖励卡池

这些卡已经落到 `StarterCardCatalog.create_stage_1_reward_pool()`，可以作为当前原型升级或宝箱奖励池的基础。当前奖励池只包含单体攻击、获得护甲和抽牌三类，不放入复合效果、群攻或条件触发卡。

`StarterCardCatalog` 同时提供 card id 解析入口，`RunState.deck_card_ids` 是 run 内卡组来源。战斗开始时会从这些 id 构建实际 `CardDefinition`，所以奖励选择加入的新卡会在后续战斗中进入抽牌堆。

| 卡牌 | 费用 | 效果 | 定位 |
| --- | ---: | --- | --- |
| 迅击 | 0 | 造成 3 伤害 | 低费补刀，会重置连击 |
| 劈砍 | 1 | 造成 8 伤害 | 打击上位替换 |
| 蓄力斩 | 2 | 造成 12 伤害 | 1 费后续连的稳定收尾 |
| 重锤 | 3 | 造成 18 伤害 | 高费终结者 |
| 格挡 | 1 | 获得 8 护甲 | 防守上位替换 |
| 铁壁 | 2 | 获得 14 护甲 | 1 费后续连的高费防守 |
| 洞察 | 0 | 抽 2 张牌 | 强找牌，但会重置连击 |

## 第一版奖励生成

- 当前原型的升级和宝箱奖励从上述奖励卡池生成。
- 同一个奖励 offer 生成 3 个不重复卡牌选项。
- 相同 run seed、关卡、等级和奖励序号会生成相同选项。
- 当前优先让 3 个选项覆盖攻击、防御和抽卡三类；如果未来卡池不足，再回退为从剩余卡牌补齐。
- 升级、宝箱或经验宝石触发升级奖励时会暂停在 reward 模式，选择奖励后只改 `RunState.deck_card_ids` 并回到探索；UI 不直接修改战斗牌库。

## 暂缓卡牌

这些卡牌需要新的核心机制，先保留设计，不进入当前可抽奖励池。

| 卡牌 | 需要机制 | 说明 |
| --- | --- | --- |
| 战术调整 | 复合效果 | 获得护甲并抽牌，等奖励 UI 和结算展示更清晰后再加入。 |
| 连锁火花 | 复合效果 | 造成伤害并抽牌，避免第一版奖励池过早出现双重收益。 |
| 横扫 | 群攻 | 需要多敌人战斗展示和目标反馈更完整后再加入。 |
| 压制 | 复合效果 | 造成伤害并获得护甲，等攻防一体类牌有更明确定位后再加入。 |
| 余势 | 复合效果 | 获得护甲并抽牌，暂时不进入纯抽卡/纯防御分类。 |
| 破甲击 | 条件伤害 | 目标有护甲时额外伤害。 |
| 野步 | 连击保护 | 让下一张牌不因低费用重置连击。 |
| 激发 | 法力变化 | 获得法力并抽牌。 |
| 保留姿态 | 保留手牌 | 选择或标记一张手牌保留到下回合。 |
| 处决 | 击杀奖励 | 击杀时额外获得经验。 |
| 宝石切割 | 奖励 hook | 下一次宝箱多一个 modifier 选项。 |
| 回响 | 复制触发 | 下一张攻击牌复制一次，需要触发上限。 |
