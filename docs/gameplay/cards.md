# 卡牌设计

## 设计目标

第一版卡池服务三个目标：

- 让玩家理解严格的费用阶梯会延续连击：上一张牌 2 费时，下一张只有 3 费能续连，同费、低费或跳到 4 费都会重置。
- 用卡牌复刻《Vampire Survivors》基础武器的攻击形态：最近目标、横向穿透、连续投射物、随机落点、弹跳、环绕区和清屏。
- 先只使用现有结算字段：伤害、护甲、抽牌、目标范围和命中次数；不引入保留、复制、临时法力、击杀奖励或条件触发。

## 目标模式

| 模式 | 说明 | 对应手感 |
| --- | --- | --- |
| `SINGLE_ENEMY` | 自动选当前马上攻击的前排敌人；可配置多次命中同一目标 | 魔杖、飞刀 |
| `FRONT_ROW` | 命中当前前排所有敌人 | 鞭子、大蒜、国王圣经 |
| `RANDOM_ENEMIES` | 基于战斗 seed 随机命中若干存活敌人 | 火焰魔杖、圣水、闪电戒指、白鸽、黑翼 |
| `BOUNCE` | 从当前目标开始，在存活敌人之间弹跳若干次 | 斧头、十字架、符文追踪器、骨头 |
| `ALL_ENEMIES` | 命中当前遭遇中所有存活敌人，包括后排 | 五芒星、樱桃炸弹、法力之歌 |
| `SELF` | 只影响玩家 | 月桂、空白之书、拼写器、复制器 |

`StarterCardCatalog` 同时提供 card id 解析入口，`RunState.deck_card_ids` 是 run 内卡组来源。战斗开始时会从这些 id 构建实际 `CardDefinition`，所以奖励选择加入的新卡会在后续战斗中进入抽牌堆。

## 第一版奖励生成

- 当前原型的升级和宝箱奖励从上述奖励卡池生成。
- 同一个奖励 offer 生成 3 个不重复卡牌选项。
- 相同 run seed、关卡、等级和奖励序号会生成相同选项。
- 当前优先让 3 个选项覆盖攻击、防御和抽卡三类；复合牌按主要用途进入攻击或防御桶，如果未来卡池不足，再回退为从剩余卡牌补齐。
- 随机命中由战斗 seed 驱动，保持规则测试和回放确定性。
- 升级、宝箱或经验宝石触发升级奖励时会暂停在 reward 模式，选择奖励后只改 `RunState.deck_card_ids` 并回到探索；UI 不直接修改战斗牌库。

## 暂缓卡牌

这些卡牌需要新的核心机制，先保留设计，不进入当前可抽奖励池。

| 卡牌 | 需要机制 | 说明 |
| --- | --- | --- |
| 血鞭 | 吸血/治疗 hook | 鞭子的进化形态，需要按伤害或击杀回血。 |
| 千刃 | 复制/额外投射物 | 飞刀进化形态，需要更明确的额外命中上限。 |
| 天堂之剑 | 暴击 | 十字架进化形态，需要暴击规则。 |
| 邪恶晚祷 | 持续光环 | 国王圣经进化形态，需要持续回合或常驻环绕。 |
| 华丽月亮 | 经验吸取 | 五芒星进化形态，需要地图 XP 吸取 hook。 |
| 破甲击 | 条件伤害 | 目标有护甲时额外伤害。 |
| 野步 | 连击保护 | 让下一张牌不因低费用重置连击。 |
| 激发 | 法力变化 | 获得法力并抽牌。 |
| 保留姿态 | 保留手牌 | 选择或标记一张手牌保留到下回合。 |
