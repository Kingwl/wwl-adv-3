# 玩法功能

## 方向

`wwl大冒险3` 是 2D roguelite 卡牌地牢游戏。第一个原型聚焦网格地牢探索、卡牌驱动战斗、combo 缩放、run 内奖励，以及轻量长期成长。

## 已实现

- 卡牌定义：id、显示名称、mana 费用、伤害、block、抽牌数和目标模式。
- 带 seed 的 deck 初始化、洗牌、抽牌、手牌和弃牌堆。
- Combo 状态：费用不下降会延续连击，低费用卡会重置连击。
- 使用 basis points 表达的整数 combo 倍率：按连击层数线性放大，1 连 100%、2 连 200%、3 连 300%、4 连 400%。
- 战斗者状态：生命、block、伤害吸收和失败判断。
- 战斗状态：玩家回合初始化、出牌校验、卡牌效果、敌人多排队列、单体攻击自动目标、敌人回合伤害、胜利和失败。
- Starter deck 卡牌目录：打击、闪电、防守和专注。
- 第 1 关奖励卡池第一版：7 张攻击、防御和抽卡三类纯效果卡。
- 卡牌目录支持从 run deck 的 card id 构建实际战斗牌库。
- 核心奖励生成第一版：升级、宝箱和经验宝石触发的升级奖励可基于 seed 生成 3 个不重复卡牌选项，并尽量覆盖攻击、防御和抽卡三类；触发奖励后会进入 reward 模式，选择奖励后才回探索。
- 核心地牢地图状态：tile 类型、关卡配置、玩家位置、敌人/拾取物占位、出口、fixture 加载和 debug 字符串。
- 地图移动规则：墙、越界和非四方向移动会阻挡；敌人格子触发遭遇；拾取物收集后清空；击败首领后出口可交互。
- RunState 初版：seed、关卡序号、生命、mana、等级、XP、run deck、物品列表、奖励序号、关卡启动和升级阈值结算。
- RunController 初版：提供核心玩家命令入口，统一移动、自动遭遇、出牌、结束回合、胜利清场、XP 掉落、拾取物效果、奖励应用、关卡切换和 run 结束，供 UI 和流程测试共用。
- 敌人队列规则：每场遭遇可有多排敌人，每排最多 5 个；只有前排敌人会攻击；前排清空后后排补上，补位敌人本回合待命，下一轮敌人回合才会攻击。
- 敌人 XP 掉落：普通敌人 3 XP、精英 8 XP、首领 14 XP；第 1 关首领路线约 1 次升级，清图约 2 次升级，避免早期成长过快。
- 固定第 1-2 关 fixture：第 1 关 16x10 地图，12 个敌人，3 个拾取物，1 个出口；第 2 关 18x10 地图，12 个敌人，4 个拾取物，1 个出口；击败首领会解锁出口；通过 `RunState.start_stage_1()` 和 `RunState.start_stage_2()` 接入。
- 地图拾取物效果：宝箱触发 3 选 1 卡牌奖励，治疗恢复 10 生命，经验宝石获得 5 XP 并可触发升级奖励。
- 最小 run 场景：绘制第 1 关地图网格，支持选中格子、查看格子详情，以及键盘、鼠标和触摸操作。
- 最小战斗 UI：地图相邻敌人会创建 `CombatState`，用独立卡片按排显示敌方队列、前排/后排、当前目标、可攻击/待命状态；单体攻击自动选择本轮马上攻击的前排敌人，若本轮没有敌人能攻击则选择最靠前的前排敌人；玩家可通过键盘选择手牌、确认出牌，也可通过鼠标或触摸点击手牌出牌；胜利后回到地图清除敌人。
- 最小奖励 UI：升级、拾取宝箱或经验宝石升级时显示 3 个卡牌奖励选项，支持鼠标和键盘选择，确认后加入 run deck。
- 最小 Run 结束 UI：玩家死亡显示冒险结束，第 2 关出口显示原型通关，并支持重新开始。

## 计划

- 第 3 关原型 run，延续第 2 关 fixture 切换结构。
- 玩家地图漫游，包括敌人交互、拾取物、出口和关卡清理。
- 锻造、祭坛等其他拾取物效果。
- 影响战斗、地图生存或奖励流程的被动物品。
- 卡牌奖励和卡牌升级规则。
- 遗物或被动 modifier。
- 参考 Vampire Crawlers 的滚雪球机制：费用灵活卡、卡牌 modifier、进化配方和确定性级联触发。
- 敌人职责：群怪、肉盾、玻璃炮、护盾怪、吸取怪、精英和 boss。
- 地图拾取物和特殊格子：食物、XP 宝石、宝箱、锻造、祭坛、陷阱、钥匙和出口。
- 构筑流派：combo 终结者、长链、护甲引擎、XP 经济和溅射清场。
