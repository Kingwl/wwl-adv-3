# UI

这里放 UI 界面范围、场景边界和视觉验证计划。

## 当前界面

- `game/scenes/run.tscn`：最小 run 场景，启动后显示第 1 关地图网格、玩家状态、选中格子详情和移动按钮；支持键盘、鼠标和触摸操作，相邻地面格可直接移动，相邻敌人可直接进入最小战斗 UI。战斗界面聚焦敌方状态和手牌区，手牌支持键盘选择/确认、鼠标 hover 同步选择和点击出牌。
- `game/scenes/start.tscn`：早期启动标题场景，保留作为简单回归对象。
