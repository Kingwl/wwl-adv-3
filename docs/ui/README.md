# UI

这里放 UI 界面范围、场景边界和视觉验证计划。

## 当前界面

- `game/scenes/run.tscn`：最小 run 场景，启动后显示第 1 关地图网格、玩家状态、选中格子详情和移动按钮；支持键盘、鼠标和触摸操作，相邻地面格可直接移动，相邻敌人可直接进入最小战斗 UI。战斗界面聚焦敌方状态和手牌区，手牌支持左右/A/D 切牌、下/S 选中结束回合、空格/回车确认、鼠标 hover 同步选择和点击出牌；当前手牌费用不足且没有可支付手牌时会自动进入下一回合。升级奖励界面显示 3 个卡牌选项，支持鼠标和键盘选择，确认后加入牌组并回到探索。
- `game/scenes/start.tscn`：早期启动标题场景，保留作为简单回归对象。
